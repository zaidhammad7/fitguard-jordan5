# FitGuard Jordan
موقع ويب للياقة البدنية في الأردن: تمرين ذكي بالكاميرا (MediaPipe)، خريطة استشفاء عضلي، ونقاط مكافآت بالشراكة مع البنك العربي (نموذج توضيحي).

## التشغيل محلياً
الكاميرا تحتاج https أو localhost:
    python3 -m http.server 8000   # ثم افتح http://localhost:8000

## النشر
ارفع المجلد إلى GitHub ثم فعّل GitHub Pages (Settings → Pages) فيعمل عبر https.
